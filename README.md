# 霓虹蛇 · 武装远征

单页网页游戏：贪吃蛇走位，武器自动射击，局内随机强化。打开 `index.html` 即可在浏览器里玩，不需要安装、构建、后端或账号。

## 怎么玩

每节身体可以带一把武器，最多 6 把。武器会自动瞄准，玩家负责走位。主武器升到 Lv5，并且身上有对应搭档武器时，会进化成究极武器，占用原来的主武器槽。

一局战役有 20 波。每 5 波是一场首领战，共 4 位首领。通关后可以选择结算，或进入无尽模式。波次计时结束、或击败首领之后，走到地图中央的补给站购物，再开始下一波。

地图上还可能出现这些东西：

- 苹果：回血、让蛇变长，并积攒大招能量
- 武器箱：获得新武器
- 补给站：用金币买武器、祝福、治疗或大招能量
- 异世界入口：限时小地图，奖励和危险写在入口提示里
- 祭坛、黄金甲虫：局内额外事件

主菜单可以选择已解锁的蛇。另外四条蛇用蛇魂解锁。进化树里的强化会留到之后的每一局。

## 操作

| 操作 | 键位 |
| --- | --- |
| 转向 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 冲刺 | 按住 `空格`。能量会下降，松开后恢复 |
| 大招 | `E` 或 `Q`。能量满后可用 |
| 休整时开始下一波 | `N`，或点屏幕上的按钮 |
| 暂停 / 继续 | `P` 或 `Esc` |
| 静音 | `M` |
| 选择升级、商店或遗物卡片 | `1`–`9` |

手机或平板可以在画面上滑动来转向。触屏还会显示冲刺和大招按钮。窗口失去焦点时，进行中的游戏会暂停。

## 本地存档

进度只保存在这台浏览器的 `localStorage` 里，键名是 `neonSnakeArmed_v2`。

会记下这些内容：

- 蛇魂数量
- 进化树等级
- 已解锁角色和当前选择
- 音效开关
- 远征、通关、最远波次、首领、击杀、无尽记录
- 已经完成过的究极进化

页面不会发网络请求，也没有账号或服务器存档。清除这个站点的网站数据、换浏览器，或使用无痕窗口，都会看不到原来的进度。存档损坏时，游戏会忽略读档错误并用初始进度开始；写入失败时，这一次的进度不会被记住。

## 本地打开

用浏览器直接打开 `index.html`，或在本目录启动任意静态文件服务后访问它。仓库根目录有空的 `.nojekyll`，避免 GitHub Pages 的 Jekyll 处理这个纯静态页面。Pages 站点本身需要在仓库设置里打开。
